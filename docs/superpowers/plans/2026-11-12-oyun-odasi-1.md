# Oyun Odası 1. parça — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ses kanalının ortasında, kişiye özel açılan 3 boyutlu oyun odası: fotoğraflı karakterler, gerçek durumlar, TV'de yayın.

**Architecture:** Bütün 3D kodu yeni `src/renderer/room.js`'de, Three.js r128 (`src/renderer/vendor/three/`) ile. `app.js` sadece görünüm düğmesini, `renderStage` / `setSpeaking` bağlantılarını ve "Büyüt" durumunu ekler. Sunucu ve ağ değişmez.

**Tech Stack:** Electron renderer (düz JS, global fonksiyonlar), Three.js r128 + EffectComposer/UnrealBloomPass (examples/js sürümleri).

**Spec:** `docs/superpowers/specs/2026-11-12-oyun-odasi-1-design.md`

## Global Constraints

- Sürüm 1.1.0 (`npm version minor`), yayında; bu planda sürüm artırılmaz.
- Sunucuya (`server/`) ve ağ mesajlarına dokunulmaz.
- Varsayılan görünüm Klasik; seçim `settings.roomView` (boolean, `localStorage['kanki-settings']`), sadece o bilgisayarda.
- Karakter rengi `u.pingColor` (yoksa `'#ffffff'`); beyaz/çok açık renk gövdede `#c9ccd3`'e çekilir.
- Three.js internetten değil `vendor/three/` dosyalarından yüklenir; `scripts/harden.js` vendor'ı küçültmeden kopyalar (değişiklik yok).
- En fazla 30 FPS; odak dışında 5 FPS; `document.hidden` iken çizim yok.
- `settings.perfMode` → bloom, toz, gölge, ışık konileri kapalı, `pixelRatio` 1.
- WebGL açılamazsa / `webglcontextlost` / ilk 3 sn ortalama FPS < 15 → toast + `settings.roomView = false` + Klasik.
- Web istemcisinde (`S.web`) düğme gizli.
- Metinler Türkçe; kullanıcı adları HTML'e `textContent` ile yazılır.
- Her değişiklik `changelog.js`, `README.md`, `OZELLIK-FIKIRLERI.md` ile birlikte (Task 7).

## Review Focus

1. Kanal değiştirme / kanaldan çıkma / sunucu değiştirme: oda eski kanalın karakterlerini taşımamalı; kanalda değilken oda gösterilmez (bugünkü "sunucudasın" ekranı çıkar). → Task 3 testi.
2. Yalnızken: Klasik'teki "yalnızsın" kartı yerine oda tek karakterle (sen) görünür. → Task 3 testi.
3. Profil fotoğrafı oturum içinde değişince yüz dokusu güncellenmeli (`S.avatars` değişir, `renderStage` çağrılır). → Task 3 testi.
4. Sohbet panelini aç/kapa, pencere boyutu değişince tuval yeniden boyutlanmalı, bozulmamalı. → Task 2 testi (ResizeObserver).
5. Oyunda olan kişi sayısı masa sayısından (3) fazla ya da boşta olan pufan (2) fazlaysa: fazlası ayakta dolaşır, etiket yine doğru durumu gösterir. → Task 4 testi.
